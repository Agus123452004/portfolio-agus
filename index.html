Project

01
ESP32 · BTS7960 · SENSOR · ELECTRICAL

Conveyor Hot Stamping Sol Sepatu

Sistem conveyor otomatis untuk proses hot stamping sol sepatu menggunakan ESP32, BTS7960, sensor posisi, relay, dan motor DC. Sistem mengatur proses secara otomatis mulai dari deteksi posisi, menghentikan conveyor, menjalankan proses press, hingga conveyor kembali berjalan.

Peran Saya

  • Merancang alur kerja conveyor dan proses press.
  • Pemrograman kontrol ESP32 menggunakan C++.
  • Melakukan wiring, pengujian sensor, dan troubleshooting.
02
IoT · MQTT · ESP32

Mesin Press Sepatu IoT

Sistem kontrol dan monitoring mesin press sepatu berbasis ESP32 dan IoT dengan komunikasi MQTT. Sistem digunakan untuk memantau data produksi, tekanan, target produksi, mode operasi, dan status proses secara real-time melalui dashboard web.

Peran Saya

  • Memprogram ESP32 untuk mengontrol proses kerja mesin.
  • Mengintegrasikan sensor, aktuator, valve, tombol, dan komponen pendukung.
  • Melakukan pengujian, troubleshooting, dan perbaikan sistem.
03
RELAY · BLOWER VACUM · GRINDING · ELECTRICAL

Mesin Press Sepatu 3 In 1

Mesin Grinding Sepatu 3-in-1 merupakan sistem mesin yang dirancang untuk membantu proses finishing dan penggerindaan pada sepatu secara lebih terkontrol dan efisien. Sistem menggunakan komponen kontrol listrik, push button, relay, MCB, motor, dan aktuator pneumatik untuk mengatur jalannya proses mesin.

Peran Saya

  • Merancang dan melakukan wiring sistem kontrol kelistrikan mesin.
  • Melakukan instalasi serta pengujian motor dan aktuator pneumatik.
  • Melakukan troubleshooting pada rangkaian listrik dan sistem kontrol.
04
ROBOTICS · ESP8266 · CONTROL · TUGAS AKHIR

Mobile Robot Berbasis Gesture Recognition

Mengembangkan mobile robot empat roda yang dapat dikendalikan menggunakan gesture tangan. Sistem menggunakan ESP8266 sebagai mikrokontroler dan motor driver L293D untuk mengontrol pergerakan motor DC. Gesture tangan diklasifikasikan menggunakan metode K-Nearest Neighbors (KNN) menjadi beberapa perintah gerak, yaitu maju, mundur, kanan, kiri, dan berhenti.

Peran Saya

  • Merancang dan mengembangkan sistem kontrol mobile robot berbasis ESP8266.
  • Mengembangkan dan menguji sistem pengenalan gesture menggunakan KNN.
  • Melakukan pengujian, troubleshooting, dan optimasi sistem agar robot dapat merespons perintah gesture dengan baik.
