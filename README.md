# Portofolio Agus Murdiono

Website portofolio statis untuk GitHub Pages.

## Cara pakai
1. Buka `index.html` untuk preview lokal.
2. Ganti data kontak di bagian `#contact`.
3. Tambahkan foto ke folder `assets/` jika diperlukan.
4. Upload semua file ke repository GitHub Pages.

- index.html
- style.css
- script.js
